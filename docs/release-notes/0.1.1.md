# PickLight 0.1.1

文件夹管理、浏览体验与偏好设置更新。

- 左栏采用文件夹树与快速访问；顶部可搜索并切换已关联文件夹。
- 自动导入监控已关联目录。新增照片及新子文件夹中的照片归入原关联文件夹，不另建左栏项目，也不移动原始文件。
- 瀑布流支持更多列，并可用 `Ctrl + 滚轮` 调整缩略图大小。
- 新增全屏浏览、适应画布与放大后的定位小窗；黑白预览可从照片菜单切换。
- 调整偏好设置、搜索框和图标状态的外观，改善 RAW 小图切换与悬浮预览响应。
- 修复右键拖动导致的缩略图位置异常、详情区展开收起闪烁，以及文件夹筛选框误高亮。
- 提供 Windows 安装版与便携版。
